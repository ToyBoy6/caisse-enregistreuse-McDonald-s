# caisse enregistreuse McDonald's®
Ceci est une représentation bêta d'un logiciel style McDonald's®. Comme il est bêta, il y aura des changements très souvent (après, ça dépend de moi, si je code ou pas).
# Comment accéder à la caisse McDonald's® ?
Pour pouvoir se servir de la reproduction de la caisse (en un peu cliché), il bous suffit de suivre ces étapes :
- Sur téléphone, ouvrez chrome, puis allez dans www.github.com
- En haut à droite, appuyez sur les trois petits points, puis cochez le mode ordinateur.
- Une fois chargé, ouvrez mon projet, puis cliquez sur le fichier "caisse.py".
- Une fois ouvert, appuyez sur le petit logo de téléchargement, puis ouvrez le dans l'application Pydroid 3.
- Puis profitez !
